# نقطه‌ی شروع مرحله‌ی ۱۹

وضعیت: آماده‌ی تدوین طرح. هیچ آزمایش یا نتیجه‌ی مرحله‌ی ۱۹ ثبت نشده است و این سند، پروتکل نهایی آن نیست.

## مبنای تصمیم

مرحله‌ی ۱۸ با محدودیت‌های ثابت مرحله‌ی ۱۷، ظرفیت بهبود میانگین گفت‌وگویی ۴٫۱۹ واحد درصد را نشان داد؛ نویسنده ۴۴۳ پرسش LoCoMo را پوشش داده و سقفِ تشخیصی ۴۶۸ است. از ۱۵۶ شکست، ۱۰۶ مورد به جلسه‌ی شاهد دسترسی ندارند، ۲۵ مورد با هندسه‌ی ثابت ممکن نیستند و ۲۵ مورد انتخاب موفقِ مجاز دارند. این کران فقط برای همان نمایه، لنگر، ناحیه و عرض معتبر است. اگر این اشیا تغییر کنند، امکان و هزینه باید در فضای جدید دوباره محاسبه شوند.

## نخستین انتخاب پژوهشی

اولویت پیشنهادی، بررسی دسترسی به جلسه‌ی شاهد زیر یک بودجه‌ی واقعیِ ثابت است؛ سهم این محدودیت از شکست‌ها بیشتر از شکستِ انتخاب درون فضای فعلی است. پیش از انتخاب نهایی باید آن را با دو مسیر دیگر، اصلاح تخصیص زمینه و ارزیابی روی شاهد ریزتر، مقایسه کرد. الگوریتم و داده‌ی مرحله‌ی ۱۹ هنوز انتخاب نشده‌اند.

- [ ] یک سوال محدود انتخاب و نزدیک‌ترین پیشینه‌ی روز درباره‌ی آن بررسی شود؛ چند متغیر به‌صورت هم‌زمان آزاد نشوند.
- [ ] داده از نظر مجوز، نسخه، سطح برچسب و هم‌پوشانی با داده‌های قبلی بررسی شود؛ استفاده‌ی دوباره اکتشافی بماند.
- [ ] اگر آزمون مستقل ادعا می‌شود، جداسازی یا منبع واقعا مناسب پیش از تنظیم روش تعیین شود. اگر داده‌ی کنترل‌شده ساخته شد، سازنده، بذر، شاهد معلوم و کنترل دشواری ثبت شوند.
- [ ] طرح و تنظیمات، معیار اصلی، واحد مستقل، سقف هزینه، کنترل‌ها و قاعده‌ی توقف پیش از امتیازدهی ثبت شوند.
- [ ] برای روش‌هایی با لنگر یا تخصیص متفاوت، هزینه و فضای انتخاب صریح شوند و سقف هر فضا جدا محاسبه شود؛ سقف ۴۶۸ به معماری تازه تعمیم داده نشود.
- [ ] برچسب مرجع فقط وارد ارزیابی و ممیز آفلاین شود؛ انتخاب متن عملی در زمان اجرا آن را نبیند.
- [ ] کنترل قطعه‌ی فقط نوبت خالی برای آزمایش‌های آینده تعریف شود؛ نتیجه‌ی تاریخی اصلاح پسینی نشود.
- [ ] شاخه و خروجی‌های جدا ایجاد و baseline مرحله‌ی ۱۸ حفظ شوند؛ آزمون‌های هزینه، گواه و عدم نشت برچسب برقرار بمانند.
- [ ] فصل روش، نتایج و محدودیت‌های تحویل کارشناسی و آمادگی دفاع هم‌زمان تکمیل شوند.

## حدود اجرا و ادعا

پروژه تک‌نفره و قابل اجرا روی CPU باقی می‌ماند و به جذب شرکت‌کننده، EEG یا API تجاری پرهزینه وابسته نمی‌شود. تعداد بیشتر بذر یا پرسش از همان تاریخچه‌ها استقلال تازه نمی‌سازد. پوشش واژه‌ی مرجع با کفایت معنایی یا صحت پاسخ یکسان نیست. تا تثبیت طرح و اجرای مستقل، نتیجه یا ادعای نوآوری برای مرحله‌ی ۱۹ وجود ندارد.

با سپاس از استاد امیر نوری، راهنمای دانشگاهی پروژه، و دکتر آرش فکری، بنیان‌گذار فردیت (FARDIAT)، مجتمع فوق تخصصی مغز و شناخت، برای آموزش علوم اعصاب شناختی و بررسی و تایید پروپوزال.
