## Preserved failures and repairs

1. During pre-scoring implementation review, the independent scorer's access
   lookup was changed to avoid creating missing-session dictionary keys. Its
   regression case ran before19A. The source-backed historical scorer was never
   changed, and all3,594 original centered/writer conditions match exactly.
2. The registered reserve4 policy changes only8/599 and1/609 queries. The five
   shuffled-label controls change almost no selections. This manipulation check
   prevents interpreting the null primary effect as a strong test of every
   session-diverse retrieval policy. The19A result and failed advance rule stay.
3.19B was added explicitly after this observation. It matches anchor-edit count,
   retains rank1, and adds an exact combinatorial access expectation. It is
   exploratory, with no fresh or confirmatory evaluation claim.
4. One initial19B saved gzip row artifact was found empty by persistence checks,
   despite a completed computation and saved summary. Its cause was not established.
   It was rejected. Two subsequent complete runs produced identical query files,
   row files and summaries; they also reproduce the original computed summary.
   The accepted canonical run has clean tracked state at start, commit212d4a6.
   No source, selector, seed, parameter or eligibility changed in this repair.
5. The portable checker initially compared in-memory integer histogram keys with
   JSON string keys. Normalizing only through JSON's wire representation repairs
   this comparison. Numerical values are compared exactly; no tolerance, rounding
   or metric change was introduced.

## Cost and statistical limits

Every primary1,024-word condition spends exactly1,024 source words, including
all10 matched-edit controls. At the secondary2,048-word budget,57 LoCoMo query–seed
controls and1 external query–seed control underspend relative to reserve8 due to
available session capacity. These counts refer to one selector; both selectors
have identical costs. They are not removed from the registered summaries.

The unit is a history/project. There are7 reused LoCoMo histories and4 fresh-source
generated projects. Question and seed counts are descriptive. Intervals are
descriptive sensitivity summaries. Coverage does not measure answer correctness,
human episodic perception, clinical brain function or philosophical meaning.

## Next decision

Do not promote reserve4 or reserve8 as a general improvement. Preserve the strong
raw baseline and all negative results. A new method should address relevance and
within-session capacity jointly under a separately registered future protocol.
The current external set is now seen. No Phase20 experiment is included.
