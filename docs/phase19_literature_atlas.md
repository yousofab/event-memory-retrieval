# اطلس پیشینه‌ی مرحله‌ی ۱۹

مرور متمرکز منابع اصلی تا ۲۵ اکتبر ۲۰۲۶. این متن مرور نظام‌مند جامع، تایید رتبه‌ی Q1 یا Q2 یا اثبات تقدم جهانی نیست. مقاله‌ی ژورنال، کنفرانس و پیش‌چاپ در وضعیت هر منبع جدا مشخص شده‌اند.

| شناسه | منبع | ارتباط و محدودیت |
|---|---|---|
| R01 | [The use of MMR, diversity-based reranking for reordering documents and producing summaries](https://doi.org/10.1145/290941.291025) | ترکیب ارتباط و کاهش افزونگی پیشینه‌ی مستقیم دارد. تنوع نتیجه به معنای پوشش شاهد کامل نیست و این مرحله اختراع تنوع‌بخشی را ادعا نمی‌کند. |
| R02 | [Relevance Is Not Sufficiency: What Actually Closes the Evidence Gap in Long-Term Memory QA](https://arxiv.org/abs/2610.09348) | BFR ترکیب شواهد مکمل و جست‌وجوی رکوردهای تازه را روی یک حافظه‌ی ثابت تفکیک می‌کند. کفایت با داور زبانی و شاخص‌های جانشین سنجیده می‌شود؛ بودجه‌ی اصلی تعداد دور، فراخوانی و رکورد است و معادل عرض واژه‌ای پنجره‌ی ما نیست. |

| R08 | [Do Personalized LLMs Need the Whole Conversation? PersonaMem-v2 و داوری پاسخ با سنجه‌ی پوشش پیام این مرحله متفاوت است؛ بازاجرا نشد. |

R یک قطعه‌ی زمینه‌ای است و شاهد کمینه نیست. چهار پروژه‌ی این اجرا محدود به fine-grained recall هستند؛ امتیاز رسمی پاسخ مقاله بازتولید نشده است. |
| R10 | [Evaluating Very Long-Term Conversational Memory of LLM Agents](https://doi.org/10.18653/v1/2024.acl-long.747) | LoCoMo منبع داده‌ی اصلی پروژه و برچسب‌های نوبت شاهد است. این پژوهش همان هفت گفت‌وگوی قبلی را دوباره تحلیل می‌کند؛ نام تاریخی held_out استقلال تازه ایجاد نمی‌کند. |
| R11 | [Multiple event segmentation mechanisms in the human brain](https://doi.org/10.7554/eLife.107955.3) | مطالعه‌ی شناختی و fMRI، نقش خطای پیش‌بینی و عدم قطعیت را در مرزهای رویداد و الگوهای عصبی بررسی می‌کند. شاهد انسانی و مدل رویداد را نمی‌توان مستقیما معادل هم‌پوشانی واژه‌ای یا هندسه‌ی پنجره‌ی متن دانست. |
| R12 | [Lost in the Middle: How Language Models Use Long Contexts](https://doi.org/10.1162/tacl_a_00638) | حساسیت استفاده‌ی مدل زبانی از متن بلند به جایگاه اطلاعات را بررسی می‌کند. وجود واژه‌های شاهد در زمینه لزوما به استفاده‌ی درست خواننده منجر نمی‌شود؛ پژوهش فعلی هیچ خواننده‌ای اجرا نمی‌کند. |

مشخصات نویسندگان، نسخه، وضعیت انتشار و دامنه‌ی خواندن در فایل JSON همراه آمده است. کنترل‌های مقالات دیگر اجرا نشده‌اند و جدول، جدول رتبه‌بندی عملکرد نیست.

## شکاف عملی و سهم محدود

پیشینه نشان می‌دهد تنوع، تکمیل شاهد، استفاده از متن خام و تشخیص خطا موضوعات تثبیت‌شده‌اند. سوال این مرحله مشخص‌تر است: وقتی فقط گروه‌بندی لنگرهای یک نمایه‌ی ثابت عوض می‌شود، آیا افزایش دسترسی، ظرفیت پوشش درون جلسه را هم حفظ می‌کند؟ گواه دقیق هر فضای جدید، کنترل شدت تعویض و داده‌ی بیرونی، این رابطه را قابل بازرسی می‌کنند. این یک سهم روش‌شناختی و تجربی محدود است و ادعای اختراع مفهوم تنوع یا درک معنای انسانی نیست.

## پیوند با ادراک رویدادی

پژوهش eLife میان خطای پیش‌بینی و عدم قطعیت پیش‌بینی در مرزبندی انسانی تمایز می‌گذارد. در این پروژه جلسه‌ی انتشار یا روز و گروه، واحد اداری داده است؛ با مرز رویدادی انسان معادل فرض نمی‌شود. نویسنده‌ی موجود نیز از تازگی واژگانی استفاده می‌کند. نتیجه‌ی بازیابی شاهد به سازوکار عصبی یا پاسخ اتاق چینی تعمیم داده نمی‌شود.

با سپاس از استاد امیر نوری، دکتر آرش فکری و فردیت FARDIAT برای راهنمایی و آموزش علوم اعصاب شناختی.
