Phase 18 provides an exact, annotation-assisted feasibility audit for the frozen Phase 17 window space. It is a completed research checkpoint, not a final thesis or a new answer-generating memory system.

## Findings

At 1,024 words, the LoCoMo writer has 443 complete-evidence successes and 156 failures. These failures separate into **106 missing-session cases, 25 geometry-infeasible cases and 25 feasible selection misses**. Exact feasible complete coverage is **468/599**, giving **4.19 percentage points** of equal-conversation headroom (descriptive seven-conversation cluster interval 2.96–5.13). Approximately 84% of the recorded failures cannot be repaired by window selection alone inside the frozen space.

For QMSum, complete coverage of all annotated relevant spans is possible for **29/244** queries at the same cap, versus 23 writer successes. This secondary joint-completeness metric differs from Phase 17's mean complete-turn recall and does not measure answer accuracy.

## Interpretation

The oracle knows reference labels offline. The 468 count is a diagnostic ceiling, not achieved performance of a new deployable retriever. Bounds hold only for supplied annotations, fixed anchors, cells, window widths and the specified budget allocator; they do not bound semantic sufficiency or answer accuracy in a different architecture. QMSum annotations are relevant summarization spans, not minimal answer evidence.

The local protocol and implementation preceded Phase 18 scoring, but there was no independent public preregistration. Both corpora and Phase 17 outcomes had already been inspected. The literature review identifies direct prior art for oracle diagnostics, sufficient context and event memory; worldwide priority is not claimed. Three illustrative numeric cases in the report were chosen after results for explanation.
