# راهنمای بازتولید مرحله‌ی ۱۸

هسته‌ی ممیز Python استاندارد و CPU می‌خواهد. آزمایش، API، مدل زبانی، GPU یا داده‌ی انسانی تازه به کار نمی‌گیرد. داده‌های خام از منبع اصلی دریافت می‌شوند و در بسته نیستند. کتاب‌ها و فایل قلم نیز بازتوزیع نمی‌شوند.

## اجرا

از ریشه‌ی یک checkout گیت با فایل‌های مرحله‌ی ۱۸:

```bash
python scripts/fetch_data.py
python scripts/fetch_phase10_data.py --download
python -m unittest discover -s tests -p 'test_phase18*' -v
python scripts/run_phase18_feasibility.py --output-dir /tmp/phase18-reproduction
python scripts/validate_phase18.py --directory /tmp/phase18-reproduction
```

هش LoCoMo، نسخه و Git-blob فایل‌های QMSum و هش طرح و خروجی والد بررسی می‌شوند. فایل‌های مرحله‌ی ۱۷ باید همان نسخه‌ی ثبت‌شده باشند. برای اجرای خود ممیز، نصب وابستگی علمی دیگری لازم نیست. تمام شرایط تاریخی از پنجره‌ی ثبت‌شده دوباره امتیاز می‌گیرند؛ روش بازیابی تازه‌ای آموزش یا انتخاب نمی‌شود.

برای تمام آزمون‌های تاریخی، از محیط نسخه‌بندی‌شده‌ی پروژه استفاده کنید؛ آزمون‌های قدیمی LSA به requirements-phase6.txt نیاز دارند:

```bash
python -m pip install -r requirements-phase6.txt
python -m unittest discover -s tests -v
```

یک آزمون مرحله‌ی ۱۴ در نبود کپی محلیِ ثابت Memora کنار گذاشته می‌شود؛ هر هفت آزمون مرحله‌ی ۱۸ باید اجرا شوند. برای اجرای هفت آزمون این مرحله، وابستگی LSA لازم نیست.

## مقابله‌ی عددی

```bash
python - <<'PY'
from pathlib import Path
for name in ('phase18_queries.json.gz', 'phase18_rows.json.gz'):
    assert (Path('results') / name).read_bytes() == (Path('/tmp/phase18-reproduction') / name).read_bytes()
print('Both numeric files are byte-identical')
PY
```

فایل summary شامل زمان، محیط و commit اجرای شماست و انتظار همانی بایتی آن وجود ندارد. در هر دو فایل عددی، ترتیب و فشرده‌سازی قطعی است. اسکریپت اجازه‌ی بازنویسی خروجی ثبت‌شده را نمی‌دهد؛ مسیر بازاجرا باید تازه باشد.

اعتبارسنجِ قابل حمل، بدون متن خام، هش‌ها، هندسه، گواه‌ها، کمترین بودجه و هویت پنجره‌های تاریخی را کنترل می‌کند. اتصال برچسب منبع به مختصات، هنگام اجرای داده‌دار بررسی می‌شود؛ این اعتبارسنجِ بدون داده، درستی معناییِ برچسب‌ها را ثابت نمی‌کند.

## خروجی‌ها

phase18_queries.json.gz شامل ۸۴۳ قراردادِ پرسش، ناحیه‌ها، عرض‌های لازم، جلسه‌های غایب و کمترین بودجه است. phase18_rows.json.gz شامل ۲۵۲۹ گروه پرسش–بودجه و معیارهای ۲۲ شرط تاریخی است؛ این گروه‌ها نمونه‌ی مستقل تازه نیستند. خروجی شامل متن پرسش، پاسخ یا مکالمه نیست. مختصات و شمارش‌ها برای بازبینی و تفسیرِ شرطی به منبع و هش آن وابسته‌اند.
