# راهنمای بازتولید مرحله‌ی ۱۷

هسته‌ی آزمایش تنها به Python استاندارد نیاز دارد؛ نسخه‌ی اجراشده 3.12.14 روی Linux x86_64 بود. matplotlib فقط برای بازساخت شکل‌ها، و python-docx/LibreOffice و B Nazanin فقط برای گزارش لازم‌اند. داده و قلم در بسته بازتوزیع نمی‌شوند. خروجی‌ها متن خام مکالمه، پرسش یا پاسخ ندارند.

## اجرا در checkout مرحله‌ی ۱۷

فرمان‌ها از ریشه‌ی مخزن اجرا می‌شوند. مسیر نتیجه باید تازه باشد؛ اسکریپت خروجی ثبت‌شده را بازنویسی نمی‌کند.

```bash
python scripts/fetch_data.py
python scripts/fetch_phase10_data.py --download
python -m unittest discover -s tests -v
python scripts/run_phase17_fixed_anchors.py --output-dir /tmp/phase17-review-run
python scripts/validate_phase17.py --directory /tmp/phase17-review-run
```

دریافت LoCoMo از منبع رسمی با SHA-256 ثبت‌شده کنترل می‌شود و در صورت تغییر منبع متوقف خواهد شد. ۳۵ فایل QMSum با commit ثابت و Git-blob hash کنترل می‌شوند. پیش از دریافت، شرایط استفاده‌ی هر مجموعه در منبع اصلی را رعایت کنید: LoCoMo در README مخزن با مجوز CC BY-NC 4.0 معرفی شده است؛ داده‌های QMSum تابع منبع و مجوزهای مجموعه‌ی رسمی هستند. کد دانلود خودکار اجازه‌ی تازه‌ای برای داده ایجاد نمی‌کند.

مقایسه‌ی فایل عددی بازاجرا با فایل ثبت‌شده:

```bash
python -c "from pathlib import Path; assert Path('results/phase17_rows.json.gz').read_bytes() == Path('/tmp/phase17-review-run/phase17_rows.json.gz').read_bytes(); print('numeric rows identical')"
```

زمان و حافظه‌ی summary به محیط وابسته‌اند و انتظار برابری بایتی آن فایل وجود ندارد. معیارهای عددی، پنجره‌ها و فایل ردیف‌ها قطعی‌اند. هش محتوای عددیِ غیر فشرده:

```text
5a8d67e308ef80b29d18e9fd08b039367930b1c7ef681d86a3494c770b4fa1e2
```

برای بازساخت شکل‌ها و تحلیل پسینی از نتایج ثبت‌شده:

```bash
python scripts/analyze_phase17.py
python scripts/audit_phase17_boundary_intervals.py
```

این فرمان فایل‌های فرعی مرحله‌ی ۱۷ و شکل‌ها را بازمی‌سازد؛ خروجی‌های مراحل قبلی را تغییر نمی‌دهد. بازتحلیل مرحله‌ی ۱۶ به ردیف‌های عددی موجود در گیت متکی است و مدل یا داده‌ی خام Memora را دوباره اجرا نمی‌کند.

## ساخت گزارش

با وجود python-docx و قلم B Nazanin نصب‌شده:

```bash
python scripts/package_phase17.py
```

تبدیل DOCX به PDF نیازمند LibreOffice یا Word است. PDF تحویلی از DOCX ساخته و تمام صفحه‌ها بصری بررسی شده است. برای اجرای علمی به قلم، Word، PDF یا matplotlib نیاز ندارید.

## کنترل‌های انجام‌شده

۵۵۶۳۸ ردیف در ۲۵۲۹ گروه جفت‌شده اعتبارسنجی شد. آزمون حذف مرز، معیار مرکزی را بازتولید می‌کند؛ آزمون‌های مصنوعی اثر مثبت و منفی شناخته‌شده دارند؛ تعویض برچسب، انتخاب را تغییر نمی‌دهد؛ نوبت ناقص کامل محسوب نمی‌شود. ۵۱ آزمون موفق و یک آزمون قدیمیِ وابسته به داده‌ی محلی Memora ردشده از اجرا بود. تمام ۹ آزمون مرحله‌ی ۱۷ اجرا شدند. نتایج جزئی در results/phase17_validation.json ثبت شده است.

## انتشار و بازبینی

پژوهشگر در ۲۱ اکتبر ۲۰۲۶ انتشار بسته و تکمیل کارهای گیتهاب را تایید کرد. شرح انتشار در [ثبت انتشار](phase17_publication.md) و نقطه‌ی شروع مرحله‌ی بعد در [تحویل مرحله‌ی ۱۸](phase18_handoff.md) آمده است. ثبت محلی پروتکل 2932298 پیش از امتیازدهی بوده، اما تاریخ‌گذاری مستقل عمومی محسوب نمی‌شود. فایل‌های PDF و Word همان نسخه‌ی تاییدشده‌ی پیش از انتشار هستند؛ عبارت توقف انتشار در آن نسخه، وضعیت تاریخی زمان تهیه‌ی گزارش است.

بررسی خودکار گیتهاب، مجموعه‌ی آزمون‌ها و اعتبارسنج نتایج ثبت‌شده را با Python 3.12 اجرا می‌کند. وابستگی‌های ثابت requirements-phase6.txt برای آزمون‌های قدیمی LSA نصب می‌شوند؛ هسته‌ی مرحله‌ی ۱۷ همچنان فقط به کتابخانه‌ی استاندارد نیاز دارد. این بررسی داده‌ی خام دریافت نمی‌کند و جای بازاجرای کامل فرمان‌های بالا را نمی‌گیرد. یک آزمون قدیمی مرحله‌ی ۱۴ در نبود نسخه‌ی محلی Memora از اجرا کنار گذاشته می‌شود؛ هر ۹ آزمون مرحله‌ی ۱۷ باید اجرا شوند.
