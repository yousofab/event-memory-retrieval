# نقطه‌ی شروع مرحله‌ی ۲۰

مرحله‌ی ۲۰ اجرا نشده است. این سند پیشنهاد برنامه‌ریزی پس از مطالعه‌ی نتیجه‌ی مرحله‌ی ۱۹ است و پروتکل نهایی نیست.

## مبنای تصمیم

رزرو چهار جلسه تقریبا بی‌تغییر بود و قاعده‌ی ادامه را تامین نکرد. رزرو هشت جلسه دسترسی را بیشتر کرد اما پوشش را در هر دو مجموعه کاهش داد؛ کنترل همسان از نظر تعداد تعویض هم پوشش بالاتری از آن داشت. بنابراین تعداد جلسه به‌تنهایی هدف بهینه‌سازی مناسبی برای این قرارداد نبود. برچسب‌های بیرونی نیز زمینه‌ی پهن دارند و با شاهد کمینه یکسان نیستند.

## سوال پیشنهادی

آیا می‌توان جایگزینی لنگر را با نشانه‌ی ارتباط و هزینه‌ی از دست رفتن ظرفیت محلی محدود کرد و بهبودی را روی ماده‌ی ارزیابی تازه حفظ کرد؟ روش دقیق، آستانه و ماده‌ی آزمون هنوز انتخاب نشده‌اند. داده‌های چهار پروژه‌ی حاضر اکنون دیده شده‌اند.

- [ ] پیشینه‌ی نزدیک دوباره بررسی و یک سوال محدود انتخاب شود.
- [ ] اگر روش تازه انتخاب شد، یک متغیر آزاد روشن و کنترل دارای شدت تغییر مناسب داشته باشد.
- [ ] پیش از تنظیم، ماده‌ی ارزیابی تازه یا مولد کنترل‌شده با حقیقت معلوم تعیین شود؛ داده‌ی مصنوعی صریح باشد.
- [ ] معیار عملی و سنجه‌ی مرجع از کفایت معنایی و پاسخ نهایی جدا بمانند؛ اجرای خواننده فقط با طرح و هزینه‌ی مشخص انجام شود.
- [ ] پیش از امتیازدهی، پارامتر، واحد مستقل، سنجه، کنترل، سقف هزینه و قاعده‌ی توقف ثبت شوند.
- [ ] کران هر فضای تازه از نو محاسبه شود؛ کنترل اشباع و یکتایی واژه حفظ شوند.
- [ ] اثر روی انتخاب لنگر و متن واقعا اندازه‌گیری شود؛ کنترل بی‌تغییر، آزمایش قوی نامیده نشود.
- [ ] فصل‌های روش و نتایج و محدودیت پایان‌نامه‌ی کارشناسی از گزارش‌های تاییدشده تدوین شوند.
- [ ] نام و نشان دانشگاه آزاد اسلامی واحد کرج و عنوان درس پروژه‌ی کارشناسی مهندسی کامپیوتر طبق الگوی گزارش درج شوند؛ قدردانی از استاد نوری ولنده، دکتر آرش فکری و فردیت نیز حفظ شود.

کار تک‌نفره و CPU و کم‌هزینه باقی می‌ماند. جذب شرکت‌کننده، EEG و API گران وارد برنامه‌ی ضروری نشده‌اند. نتیجه‌ی مثبت، نوآوری جهانی یا پذیرش دانشگاهی از پیش فرض نمی‌شود.

با سپاس از استاد امیر نوری ولنده برای راهنمایی دانشگاهی و حمایت از ایده‌های نو، و دکتر آرش فکری، بنیان‌گذار فردیت FARDIAT، مجتمع فوق تخصصی مغز و شناخت، برای آموزش علوم اعصاب شناختی و بررسی و تایید پروپوزال.
